## Remediation Standards by Document Type

### PDF — Remediate in Place
- Add document title, language, and metadata
- Full tag tree: headings, paragraphs, lists, tables
- Alt text for all images, charts, and decorative elements
- Logical reading order verified
- Bookmarks for documents over 9 pages
- Color contrast meets WCAG 2.1 AA (4.5:1 text, 3:1 UI)
- No content conveyed by color alone
- Links have descriptive text
- Verify with PAC 2024 and screen reader (NVDA or JAWS)

### PDF — Convert to Word (.docx)
- Use Acrobat Pro or comparable conversion tool
- Apply proper heading styles (Heading 1–4), not manual formatting
- Add alt text to all images
- Use accessible table formatting (header rows defined)
- Descriptive hyperlink text
- Spell-check and review converted content for accuracy
- Save as accessible .docx; optionally publish both .docx and tagged PDF
- Verify with Microsoft Accessibility Checker

### PowerPoint
- Unique, descriptive title for every slide
- Alt text for all images, shapes, charts, SmartArt
- Reading order correct in Selection Pane
- Sufficient color contrast
- No information conveyed by color alone
- Captions or transcripts for any embedded audio/video
- Verify with PowerPoint Accessibility Checker + screen reader test

## Risk & Contingency

| Risk | Mitigation |
|---|---|
| Documents more complex than anticipated | Build 2-week buffer into Phase 4; escalate early |
| Staff capacity gaps | Cross-train two team members as backup remediators |
| Tool or conversion quality issues | QA every 25 documents; adjust conversion approach as needed |
| Scope creep (new documents added) | Freeze scope at end of Phase 1; log new docs for post-deadline cycle |
| ADA regulatory guidance updates | Monitor DOJ communications; adjust standards if needed |
| Misalignment with parallel remediation team | Hold monthly sync with parallel team to confirm no overlap or gaps |
